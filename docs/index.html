O que é o Product Manager?

É uma aplicação para centralizar informações que frequentemente ficam distribuídas entre planilhas e ferramentas diferentes. O objetivo é oferecer uma visão operacional simples do catálogo e dos itens que precisam de atenção.

O projeto está em evolução. Consulte a documentação e os limites de implantação antes de utilizá-lo com dados reais ou em ambientes de produção.

Como é organizado

A aplicação web usa um servidor Python e um banco SQLite. A interface é servida como HTML, CSS e JavaScript. O repositório também mantém um núcleo C23 separado, em evolução, que não faz parte do caminho principal da aplicação web.

API

Rotas HTTP, autenticação, autorização, validação e exportação.

Persistência

Esquema SQLite para usuários, sessões, produtos, clientes, alertas e lançamentos financeiros.

Distribuição

Docker/Compose, pacotes desktop e PWA, conforme os fluxos disponíveis no projeto.

Como começar

Para desenvolvimento local, use Python 3.10 ou superior. Consulte o guia antes de configurar o primeiro administrador.

Obtenha o código

Clone o repositório e entre no diretório do projeto.

Execute e teste

Inicie a aplicação e rode a suíte automatizada antes de alterar o código.

git clone https://github.com/mnl-nox/product_manager.git
cd product_manager
python3 api/app.py

Abra http://127.0.0.1:8000 e siga o procedimento de primeiro acesso descrito na documentação.

Limites importantes

As contas compartilham um espaço de trabalho SQLite; não há isolamento multi-tenant entre organizações. O servidor Python não fornece TLS por conta própria. Para acesso remoto, configure uma implantação HTTPS adequada, proteja backups e credenciais e revise a documentação de segurança e privacidade.
