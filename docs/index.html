O projeto em resumo

Uma ferramenta para reunir informações que muitas equipes pequenas mantêm em planilhas ou sistemas diferentes. O foco é facilitar a consulta ao catálogo e destacar o que precisa de atenção na operação.

O projeto está em evolução. Consulte os requisitos, as políticas de segurança e as limitações documentadas antes de usar dados reais em produção.

Arquitetura e tecnologias

A aplicação principal é composta por uma interface HTML/CSS/JavaScript, uma API HTTP em Python e persistência SQLite. O núcleo C23 está em desenvolvimento separado e não integra o fluxo principal da aplicação web.

Interface

Páginas web responsivas, com experiência de desktop e PWA.

Servidor e API

Autenticação, autorização, validação, auditoria e exportações.

Dados e implantação

SQLite e opções de execução local, Docker/Compose e pacotes multiplataforma.

Execute localmente

Pré-requisito: Python 3.10 ou superior. Para configurar o primeiro administrador, siga o procedimento de bootstrap na documentação; não existe senha padrão.

git clone https://github.com/mnl-nox/product_manager.git
cd product_manager
python3 api/app.py

Depois, abra http://127.0.0.1:8000 no navegador e siga o fluxo de primeiro acesso.

Perguntas frequentes

Respostas rápidas para quem está conhecendo ou pretende contribuir com o projeto.

O Product Manager é gratuito?

Sim. O repositório é distribuído sob a licença MIT. Consulte o arquivo LICENSE para os termos.

Preciso instalar dependências Python?

A API e os testes foram projetados para Python 3.10 ou superior sem dependências externas obrigatórias. Outros fluxos de build podem exigir ferramentas específicas.

Posso acessar pelo Android?

Sim, por meio do PWA instalável. Para implantação remota, use HTTPS. O cache do PWA não torna a API disponível offline.

Os usuários têm dados separados por empresa?

Não. As contas compartilham um espaço de trabalho SQLite; não há isolamento multi-tenant entre organizações.

O sistema já está pronto para produção?

A prontidão depende do ambiente e da configuração. O servidor não fornece TLS por conta própria. Revise segurança, privacidade, backups e limitações antes de publicar dados reais.

Segurança e limitações

O banco pode conter dados pessoais e financeiros; proteja o arquivo e os backups. Para acesso remoto, configure HTTPS e cookies seguros. Avalie o escopo compartilhado do banco antes de usar o sistema por várias organizações.
